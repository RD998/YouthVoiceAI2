# YouthVoice AI

## Overview

YouthVoice AI is a web-based application designed to encourage youth participation in the democratic process by providing AI-assisted policy recommendations and voter awareness resources. The platform allows users to explore information related to voting, governance, and public policies through an interactive interface.

The project demonstrates how artificial intelligence can be used to present policy recommendations supported by public opinion and factual information in a simple and accessible manner.

## Features

- AI-inspired policy recommendation interface
- Interactive search input for user queries
- Policy recommendations with supporting public opinion
- Informational sections explaining the platform and its functionality
- Smooth scrolling animations using ScrollReveal
- Parallax scrolling effects
- Side navigation panel for history
- Responsive web interface

## How It Works

1. The user enters a query into the search box.
2. Clicking the **Submit** button displays a sample policy recommendation.
3. The application presents information supported by public opinion and educational content.
4. Scroll animations and parallax effects improve the overall user experience.

## JavaScript Functionalities

### Parallax Effect

Creates a scrolling effect by moving elements with the `.parallax` class at different speeds.

### ScrollReveal Animations

Animates webpage sections as they enter the viewport.

### Navigation Panel

Provides functions to open and close the side navigation menu.

- `openNav()`
- `closeNav()`

### Recommendation Display

The `getRecommendation()` function displays the hidden recommendation section when the user clicks the submit button.
